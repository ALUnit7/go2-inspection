> 更新时间：2024-12-23

## 电气接口规格

| 接口 | 说明 |
|------|------|
| XT30U-F 电源接口 | 2路 16-45V 输入（峰值60V）；1路 12V/3A 输出；1路 5V/3A 输出 |
| 千兆以太网（RJ45×2） | 1路连接 GO2，1路对外用户拓展 |
| M8 航插（百兆以太网+12V） | 1路百兆以太网（雷达专用）；1路 12V/2A 给雷达供电 |
| USB Type-A | USB 3.2 Gen2，仅 Host 模式，5V/1A，10Gbps |
| USB Type-C 全功能（DP Alt） | USB 2.0 或 DP 1.4，5V/3A |
| USB Type-C | USB 3.2 Gen2，5V/2A |
| GH1.25-4PIN | 百兆以太网，对外用户拓展 |

## 安装拓展坞

1. 用内六角 L 型扳手取下 Go2 背部盖板螺丝，打开盖板
2. 连接机身电源接口和以太网口到拓展坞对应接口，线缆固定在出线槽
3. 用 M3×50 内六角螺丝将拓展坞固定在机身背部
4. 将背部盖板固定到拓展坞盖板固定处

## 安装 D435i 深度相机

**物品清单：** 深度相机×1、固定底座×1、Type-C 线×1、支撑件×1、固定板1×1、固定板2×1、M3螺钉×2、垫片×2、紧固螺钉×2、内六角扳手×1

**安装步骤：**

1. 将 Type-C 线插入相机接口，穿过支撑件（**必须先插线再安装**）
2. 用 2 颗 M3 螺钉将固定板1和支撑件固定到相机背部孔位
3. 用 2 颗紧固螺钉依次穿过固定板1孔位、垫片、固定板2并拧紧（固定板1有4个挡位可调节高度和角度）
4. 取下 Go2 头部深度相机固定孔螺钉，将固定底座对准头部孔位固定
5. Type-C 线另一端连接到拓展坞

## 安装雷达

### MID-360 激光雷达

1. 用紧固螺丝将雷达固定到指定位置
2. 将雷达接口连接到拓展坞 M8 航插接口

### XT-16 激光雷达

1. 用紧固螺丝将雷达固定到指定位置
2. 将雷达接口连接到拓展坞 M8 航插接口

---

## 安装 D1 机械臂

1. 将四方螺母穿过拓展坞导轨，用 M4×10 内六角螺丝将机械臂固定到导轨
2. 拓展坞电源输入接口 → 机械臂电源接口；拓展坞 GH1.25-4PIN 百兆以太网口 → 机械臂以太网口

## 充电桩

### 安装

**物品清单：** 铭牌板支撑件×1、铭牌板×1、充电板×1、滚花手拧螺丝 M3×6×2

1. 用滚花螺丝将铭牌板固定到支撑件
2. 将充电板固定到支撑件（**严格按图示方向，禁止反装**）

### 使用步骤

1. 充电前检查充电电极是否有异物，用干燥抹布擦拭
2. 将充电器插入交流电，连接充电板底部电源接口，线缆固定在线槽
3. 操控 Go2 卧倒，**头部对准铭牌方向**，使底部 2 个充电电极与充电板接触
4. 充满后自动断开

> **注意：充电桩有正反极性，头部必须对准铭牌方向，禁止反冲！**

### LED 状态

| 状态 | LED 表现 |
|------|----------|
| 充电完成 | 常亮 |
| 充电中 | 500ms 间隔慢速闪烁 |
| 过流/欠压保护 | 100ms 快闪3次 → 常亮1.5s → 循环 |
| 空闲 | 呼吸灯 |

### L1 自动回充

- 需配合 L1 回充专属标定板使用（新购充电板附送）
- 目前支持 Go2 App → 3D 激光建图，后续开放 SDK 接口

**注意事项：**
- 建图前将机器狗放置在充电板上；未放定位板时只返回建图起点，不自动充电
- 充电板需水平放置，避免宽度小于 1m 的走道，周围障碍物尽量少
- L1 雷达脏污或损坏会影响回充成功率
