## SDK 介绍

`unitree_sdk2` 是宇树科技为新一代机器人开发的 SDK，封装了以下接口：

- 底层电机控制
- 高层运动控制
- 雷达点云数据
- 音视频图传
- SLAM
- 里程计

配套文档：《Go2 SDK 开发指南》

---

## 支持范围

| 机器人 | 支持情况 |
|--------|----------|
| Unitree Go2 EDU（含 Go2 X） | 支持 |
| Unitree B2 | 支持 |
| Unitree H1 | 支持 |
| 其他型号/版本 | 不支持 |
